# KODA EUDR Workspace v2.4 — staging handoff

**Prepared:** 8 October 2026. **Status:** code candidate with automated validation; no observed live deployment or UAT.

## Delivered

| Area | Behavior |
| --- | --- |
| Order Workspace | Products above Materials. Select a Material to view its Supply Chain and add relationships. Select a supplier node to view four evidence blocks. Buttons sit at each section’s lower right. Review & Complete Dossier stays visible. |
| Relationship folders | Tier 1 and later nodes have a folder under their Material named for the parent and supplier, with stable ID suffix. Four child folders: Commercial Shipping, FSC Certification, Transport, Geolocation. New evidence uploads use the relevant child. |
| Tracker | Each node gets 11 default tasks: Purchase Order, Sales Contract, COO, INV, PL, BL; Supplier FSC license, FSC Cert; Transport invoice, Delivery Note; GEO location. Due date inherits the Order due date. First ten are Purchasing department tasks; GEO location is Sourcing. A reviewer can assign a named owner. |
| Custom evidence | Add Evidence Type is scoped to selected Material/node and one of four blocks. The old Upstream Traceability block is removed from new UI. New global policy labels without a predefined block are rejected; use scoped creation. |
| Sales Order | Tier 1 displays Sales Order (KODA – Supplier 1) as a contextual reference to the Order original in `00_SO`, without copying it. Only Admin and Marketing can access that original or derivatives through app APIs. |
| My Tasks | Two columns: Overdue, Due Today, Due This Week; Awaiting My Review, Waiting for Supplier, Completed. All assigned evidence follows. Named owner/reviewer or unassigned department determines user view; Admin sees all. |
| Calendar | Days show due-task counts and open a task panel. Sheet due dates follow workbook time zone. Optional configured Google Calendar sync uses task ID, due date, and owner or department; Calendar permissions still apply. |
| Export | Order selection, separate original and human-verified AI copy columns, full or selected ZIP, progress panel, direct download. Files over 3 MB use one MiB chunks; source total limit 23 MiB and ZIP limit 25 MiB. |
| New user | Admin provisions Firebase account; random temporary password shown once. Mandatory first-login password change is enforced by server before Workspace actions. Refresh tokens are revoked after change. It is not a time-based OTP. |

## Migration

After backing up and completing earlier migrations, run `migrateV24(true)` and review folder counts, `unmapped` historical tasks and `unmapped_policies`. Resolve ambiguous labels with a business owner; map historical task `evidence_block` to the correct logical block. Run `migrateV24(false)` and repeat dry run. It adds missing folders and default tasks, remaps recognized old blocks, preserves existing file IDs, approvals, task owners, and physical file paths. Existing Material-level evidence remains recorded. No new schema column is introduced. Logical tracker blocks are `01_Commercial_Shipping`, `02_FSC_Certification`, `03_Transport`, and `04_Geolocation`; Drive folder display names omit prefixes.
